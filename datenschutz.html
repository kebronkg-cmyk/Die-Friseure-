Was beim Aufruf passiert

Diese Website ist eine statische Seite und wird über GitHub Pages (GitHub Inc., USA) ausgeliefert. Beim Aufruf verarbeitet GitHub technisch notwendige Daten wie IP-Adresse, Zeitpunkt und aufgerufene Datei, um die Seite auszuliefern und vor Missbrauch zu schützen (Art. 6 Abs. 1 lit. f DSGVO). Wir selbst werten diese Daten nicht aus.

Keine Cookies, kein Tracking

Wir setzen keine Cookies, keine Analysewerkzeuge und keine eingebetteten Dienste. Schriften und Bilder liegen auf demselben Server wie die Seite.

Was Ihr Browser sich merkt

Wenn Sie einen Salon oder eine Haarlänge wählen, speichert Ihr Browser diese Wahl lokal (localStorage), damit sie beim nächsten Besuch schon eingestellt ist. Diese Angabe verlässt Ihr Gerät nicht. Sie können sie über die Einstellungen Ihres Browsers löschen.

Links zu anderen Diensten
